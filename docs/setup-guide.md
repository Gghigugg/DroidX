# Setup guide

1. Open the `ig-agent-os-rebuild` branch in GitHub.
2. Import the repository into Vercel only after reviewing the branch contents.
3. Select the Next.js framework preset.
4. Deploy the scaffold; no API credentials are required for the demo dashboard.
5. To develop locally, use Node.js 20.9+, run `npm install`, then `npm run dev`.
6. Do not add Meta credentials until an app, eligible Instagram professional account, redirect URI, and required permissions are configured.
7. Keep all real secrets in server-side environment variables.
